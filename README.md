# Chronic

Chronic — библиотека для Elixir, которая разбирает естественные текстовые выражения даты и времени. Она возвращает `NaiveDateTime` и timezone offset, позволяя превращать фразы вроде `tuesday 9am` в программно пригодные значения.

## ✨ Особенности
- Разбирает даты и время в свободной текстовой форме.
- Возвращает результат в виде `{:ok, time, offset}`.
- Учитывает текущий момент времени при интерпретации даты.
- Позволяет передавать собственное значение `currently` для локального времени.
- Возвращает понятные ошибки для неизвестных форматов и невалидных дат.

## 🚀 Быстрый старт
### Подключение зависимости
Добавьте библиотеку в `mix.exs`:

```elixir
defp deps do
  [
    {:chronic, "~> 3.2"}
  ]
end
```

Затем установите зависимости:

```bash
mix deps.get
```

### Базовый пример
```elixir
{:ok, time, offset} = Chronic.parse("tuesday 9am")
```

### Использование локального времени
```elixir
{:ok, time, offset} = Chronic.parse("tuesday at 12pm", currently: :calendar.local_time)
```

## 📁 Структура проекта
- `lib` — исходный код парсера естественных дат и времени.
- `test` — тесты и проверка поведения парсинга.
- `mix.exs` — описание проекта, зависимостей и HexDocs-конфигурации.

## 🛠 Использование
### Обработка ошибок
```elixir
case Chronic.parse(input) do
  {:ok, time, offset} ->
    {:ok, time, offset}

  {:error, reason} ->
    {:error, reason}
end
```

### Возможные ошибки
- `{:error, :unknown_format}` — если формат не распознан.
- `{:error, :invalid_datetime}` — если дата невозможна, например `January 32nd`.

### Что важно помнить
По умолчанию библиотека ориентируется на UTC-время. Если нужна интерпретация относительно локального времени пользователя, лучше передавать опцию `currently`.
